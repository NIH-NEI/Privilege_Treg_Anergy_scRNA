## Data Analysis Tools/Methods used for the "Ocular immune privilege in action" project

1. [Tools/eye_privilege_seurat_figures.R](Tools/eye_privilege_seurat_figures.R)  : Input files and R Commands used for generating the main Seurat workflow figures presented in the manuscript (corresponding RData object is deposited here in zenodo).
2. [Tools/eye-privilege-scenic-velocity-trajectory-figures.R](Tools/eye-privilege-scenic-velocity-trajectory-figures.R)  : Input files and R Commands used for generating the SCENIC and Trajectory figures presented in the manuscript (corresponding RData object is deposited here in zenodo).
3. [Tools/fig7_ab_velocity.py](Tools/fig7_ab_velocity.py)  : Python script used for generating the velocity figures presented in the manuscript (corresponding velocity file is deposited here in zenodo).
4. [Tools/GexWorkflow_eye_naive_20231124.Rmd](Tools/GexWorkflow_eye_naive_20231124.Rmd)  : R Commands used for the main single cell analysis workflow.
